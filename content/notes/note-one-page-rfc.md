這份模板是 [[written-decision-culture|非同步書面決策]] 的配套工具，刻意限制在 A4 一頁（約 600–800 字）內完成：

```
1. 背景與核心問題（我們試圖解決什麼具體痛點？）
2. 現狀成本（如果維持現狀不做改變，三個月後會發生什麼事？）
3. 方案比較：
   - 方案 A（建議採用）：優點 / 風險 / 所需資源
   - 方案 B（替代方案）：為何不優先選它？
4. 關鍵待決問題（需要本次審閱者拍板的 1-2 個問題）
```

重點在於**提案人必須先亮出自己的傾向（建議方案）**，而不是丟出三個沒有立場的選項讓主管填空。
