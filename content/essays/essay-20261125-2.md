# 自主學習共備工作坊｜討論摘要

## 一、學生的困難：不是沒有想法，而是缺乏嘗試的勇氣

教師設計學習單時，往往認為內容完整、引導清楚，但實際交給學生操作時，卻發現學生不知道如何下筆。

其背後可能有以下原因：

- 不知道自己的想法是否符合教師的期待。
- 害怕寫錯，缺乏嘗試的勇氣。
- 入班指導教師與學生缺乏既有的信任關係。
- 擔心自己的興趣與主題（例如二次元文化）不被教師認同。
- 學習單的開放程度超過學生當前能夠掌握的範圍。

**學生不一定是能力不足或缺乏想法，而是尚未建立表達想法的安全感。**

## 二、學習單設計：降低學生開始行動的門檻

學習單應考量各校學生的特質與學習起點，不能只從教師的角度判斷教材是否完善。

**第一階段｜完整句型示範**

直接提供完整的問題範例，例如：「為什麼學習歷程檔案會造成高中生的壓力？」

**第二階段｜模仿與填空**

讓學生依照範例，替換成自己感興趣的主題及探究對象。

**第三階段｜自主提問**

逐漸減少引導，讓學生自行形成問題、表達想法。

教材應多採用貼近學生世代與生活經驗的案例，透過具體示範建立學生的信心，再逐步走向開放式探究。

## 三、各校自主學習課程的實施經驗

| 實施模式     | 課程安排             | 主要目標       |
| -------- | ---------------- | ---------- |
| 9 小時引導課程 | 線上主講搭配現場教師指導     | 完整體驗自主學習流程 |
| 6 小時引導課程 | 學生已有初步主題構想       | 完成基本自主學習規劃 |
| 全學年自主學習  | 每週一節引導課程，搭配分階段執行 | 從主題發想到成果整理 |

不同學校的學生特質、校園文化及課程時間均有所差異，因此不宜要求各校採取完全相同的教學模式。

### 全學年自主學習實施流程

1. **上學期第二次段考前**

   每週安排一節引導課程，學生利用課堂時間撰寫計畫，經過初審、複審及反覆修正。
2. **上學期第二次段考後**

   正式進入自主學習執行階段。
3. **下學期第二次段考前後**

   完成主要執行任務，逐步進入成果整理階段。
4. **學年後期**

   彙整學習成果與歷程紀錄。

## 四、線上與實體協作的教學模式

採用一位教師線上主講、多位教師現場指導的方式，具有跨校推動自主學習課程的可行性。

成功的關鍵在於：

- 現場教師必須充分掌握教材、數位工具與操作流程。
- 現場教師能即時協助學生排除學習困難。
- 線上主講教師提供一致的學習框架與步驟。
- 讓學生至少實際走過一次完整的自主學習流程。

引導課程不一定要求學生當下就完成真正的自主學習專案，而是讓學生理解整體框架，知道未來遇到新的學習主題時，可以如何展開行動。

## 五、共備工作坊的最終目標

建立一套能夠因應不同學校文化、學生程度及課程安排的**自主學習共用教材資源庫**。

共同版教材並不是建立單一標準答案，而是彙整多種可行的教學模式，讓未來接手自主學習課程的教師能夠快速取得適合的資源。

各校不必擔心自己的做法過於簡單，因為對某校而言理所當然的方法，可能正是其他學校所欠缺的經驗。

## 六、後續待辦事項與時程

| 時間           | 負責對象   | 待辦事項                  |
| ------------ | ------ | --------------------- |
| 即日起          | 各校教師   | 整理各校自主學習教材、引導流程及實施方法  |
| 2027/01/04 前 | 各校教師   | 上傳並繳交共備成果             |
| 01/05～01/17  | 共備工作團隊 | 彙整各校資料、分類教學模式及整理共同版教材 |
| 2027/01/18   | 全體共備教師 | 下次共備，分享與討論各校成果        |

## 七、本次共備的核心共識

- **以學生的學習起點為基礎**，而非以教師的能力設計教材。
- **先提供示範，再要求自主**，降低學生開始行動的門檻。
- **先掌握流程，再追求成果**，讓學生建立可遷移的自主學習能力。
- **尊重各校文化與差異**，不強求單一實施模式。
- **透過共備累積共享資源**，降低未來教師接手課程的負擔。

## 核心教育理念

> 自主學習的引導，不只是教會學生如何完成一份計畫書，更重要的是讓學生擁有提出想法、嘗試行動以及面對錯誤的勇氣。
>
> 教師共備的價值，也不是尋找唯一的最佳教學方法，而是建立多種可以被選擇、調整及複製的成功模式。
