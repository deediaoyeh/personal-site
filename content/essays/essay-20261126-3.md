# **善用AI協作打造學習歷程｜教師研習摘要**

## **一、課程核心理念**

學習歷程不應只是高中生為了大學申請入學而準備的備審資料，而是培養學生終身學習、知識管理與問題解決能力的過程。

學生未來會遇到許多書本沒有提及、父母沒有教過、老師也無法預先指導的問題。面對這些問題，學生必須具備持續學習與自主解決問題的能力。

然而，目前高中教育仍偏重學科知識與考試準備，較少系統性地教導學生「如何學習」。

學習歷程所培養的能力，未來可以延伸應用至：

- 大學課程的閱讀與資料整理。
- 獎學金與研究所申請。
- 求職、轉職及個人專業成果的呈現。
- 生活中的自主學習與問題解決。
- 個人知識管理與終身學習。

**學習歷程是練習的場域，知識管理才是學生真正需要帶走的能力。**

## **二、課程目標與學生起點**

學生起點

# **一張白紙**

假設學生完全不了解學習歷程，不知道何時開始、如何準備，以及遇到問題時該怎麼辦。

**目標一｜理解完整歷程**

了解高一到高三各學期、各學年應完成的任務與重要時間節點。

**目標二｜掌握資料整理方法**

知道應準備哪些內容，以及如何蒐集、整理、篩選、加工與呈現資料。

**目標三｜具備問題解決能力**

遇到困難時，能善用 AI 尋求解釋、範例與解決方案，而非停止學習。

## **能夠自主完成學習歷程的學生**

設定學習目標就像設定導航系統的目的地。無論是教師規劃課程，或是與 AI 協作設計教材，都必須先明確定義希望學生達成的學習表現。

## **四、學習歷程的四大教學模組**

整套課程由四份簡報、四份對應學習單組成，教師可以依照不同年級、學生程度與授課時間，拆分成獨立的教學模組。

**01 概論｜建立全貌**

了解整個高中學習歷程的時間軸

**02 備料｜累積與加工**

高一、高二持續蒐集及整理資料

**03 盤點與勾選｜精準配對**

高三依據不同校系需求篩選資料

**04 擺盤｜敘事與呈現**

完成具備個人特色的備審資料

**AI 協作貫穿所有階段**

解釋、示範、篩選、檢核、回饋與問題解決

### **模組一：概論——建立學習歷程的全貌**

**適用對象：高一學生，亦可作為各年級的複習教材。**

首先協助學生理解學習歷程制度與時間安排，避免三種常見盲點。

| 常見盲點 | 學生迷思      | 教學重點            |
| ---- | --------- | --------------- |
| 時間盲點 | 高三再開始整理就好 | 高一開始累積，每學期定期整理  |
| 品質盲點 | 資料上傳越多越好  | 精選優質且具代表性的作品    |
| 角色盲點 | 老師會幫我處理   | 理解學生、教師與系統各自的任務 |

教學方式：

- 使用視覺化簡報呈現三年的重要時間節點。
- 引入異世界、遊戲闖關等概念，提高學生的閱讀興趣。
- 讓學生繪製自己的學習歷程時間軸。
- 搭配學習單，要求學生回到簡報尋找答案。
- 依據學生所在年級調整教材，不必一次講完所有規定。

### **模組二：備料——高一、高二的資料累積與加工**

**適用對象：高一、高二學生。**

重點不只是累積資料，而是讓學生理解什麼樣的資料具有價值，以及如何將原始資料加工成有意義的學習成果。

導入 CODE 知識管理方法：

# **C**

**Capture｜蒐集**

留下作品、照片、紀錄、學習成果與原始素材。

# **O**

**Organize｜組織**

依學科、主題、時間與用途分類整理。

# **D**

**Distill｜提煉**

反覆回顧，抓出重點、亮點及能力證據。

# **E**

**Express｜表達**

將整理後的資料轉化為有意義的成果。

一份完整的課程學習成果，應引導學生思考下列元素，而非只上傳一張照片、獎狀或最終作品。

| 元素      | 引導學生思考的問題     |
| ------- | ------------- |
| 標題與基本資訊 | 這是一份什麼樣的作品？   |
| 摘要      | 為什麼要讓教授看這份資料？ |
| 動機      | 我為什麼要做這件事？    |
| 學習過程    | 我採取了哪些行動？     |
| 具體成果    | 我完成了什麼？有哪些證據？ |
| 心得與反思   | 我有哪些改變與成長？    |

反思可以從教育目標的三個面向切入：

- **認知：** 我理解了哪些新知識？
- **情意：** 我的態度、興趣與價值觀有何改變？
- **技能：** 我現在能夠完成哪些以前不會的事情？

學生完成作品後，可以提供檢核標準，要求 AI 扮演特定學科教師，協助檢視內容是否完整，並提出修改建議。

### **模組三：盤點與勾選——依據校系需求精準配對**

**適用對象：高三學生，特別是申請校系確定之後。**

不同大學即使是相同科系，重視的能力、特質與備審資料也可能有所差異。

因此，學生必須理解兩類重要參考資料：

| 資料來源                   | 查詢重點              |
| ---------------------- | ----------------- |
| ColleGo! 大學選才與高中育才輔助系統 | 學系重視的能力、特質及學習方向   |
| 大學申請入學校系分則及審查資料準備指引    | 各校系實際要求的資料項目與審查重點 |

依校系需求選擇資料，而非將同一份資料送給所有校系。

此階段最重要的是讓學生理解：

**資料篩選的依據是能力與證據，而不是數量。**

AI 可以協助比對資料、推薦作品、解釋選擇理由，但最後仍應由學生確認，必要時與教師討論。

另外，應提供最終檢核表，讓學生在上傳前逐項確認。

### **模組四：擺盤——備審資料的敘事與呈現**

**適用對象：高三學生。**

主要處理學習歷程自述、多元表現綜整心得及其他備審資料的呈現。

學生必須將過去累積的資料串成一條有意義的學習脈絡，而不是將不同作品堆疊在一起。

可以運用 STAR 架構引導學生敘述：

# **S**

**Situation 情境**

當時面對什麼情況或問題？

# **T**

**Task 任務**

我需要完成什麼任務？

# **A**

**Action 行動**

我採取了哪些具體行動？

# **R**

**Result 結果**

產生什麼成果？我學到了什麼？

呈現資料的四個重點是個人故事、時間脈絡、校系重視的能力，以及具體證據與圖表。

在這個階段，可以讓 AI 協助檢查架構、調整文字、提供圖表建議，但不宜由 AI 從頭到尾代寫。

**學生必須保有內容的主控權與個人觀點。**

## **五、重新思考教師與 AI 的角色分工**

老師願意協助學生，但當十個學生同時提出十個不同的問題時，教師不可能立即回應所有人。

部分學生會因為無法及時獲得協助而放棄學習。

因此，本課程希望建立一套新的學習支持機制：

| AI 可以協助的工作 | 教師應發揮的專業    |
| ---------- | ----------- |
| 降低知識的理解難度  | 掌握學生的真實學習起點 |
| 提供大量範例與示範  | 判斷適合學生的學習策略 |
| 解答重複性的問題   | 處理個別學生的深層困難 |
| 協助資料篩選與檢核  | 確認內容品質及正確性  |
| 提供初步回饋     | 引導反思與高層次思考  |
| 生成教材及學習單   | 教學設計與評量設計   |

**在老師還來不及接住學生的時候，讓 AI 先接住他。**

AI 的價值不是取代教師，而是讓教師有更多時間處理真正需要教育專業的事情。

## **六、AI 時代的教材與教學活動設計**

### **1. 使用圖卡取代大量文字說明**

教師可以先用口述方式說明自己的課程構想，再請 AI 摘要、整理與繪製圖卡。

教師口述課程構想

AI 轉錄與摘要整理

確認內容及教學架構

生成課程總覽圖卡

檢查錯誤並修正

教師真正需要投入時間的，是思考課程的內容與架構，而不是花費大量時間進行排版。

### **2. 簡報與學習單必須搭配**

只有簡報容易形成教師單向講述，學生可能分心，甚至完全沒有產生學習行為。

學習單具有以下功能：

- 讓學生主動閱讀簡報並尋找答案。
- 提供明確的學習程序，讓中途分心的學生可以重新接續。
- 使教師看見學生的理解程度。
- 讓學生在課程中實際產出成果。
- 保護學生有限且珍貴的注意力。

### **3. 降低學習活動的認知負荷**

對於能力尚未建立的學生，過度開放的問題往往會造成沉重的認知負擔。

從高度鷹架逐步走向自主學習

勾選

填空

模仿範例

結構式回答

開放式表達

由簡單、明確的任務開始，逐漸增加學生自主思考與表達的空間。長條僅為概念示意。

建議學生可以使用電腦閱讀教材，但在適當的學習活動中，仍使用紙筆完成學習單。

### **4. 教材模組化與在地化**

研習提供的教材是通用版本，而非要求所有學校採用相同的教學方式。

教師應建立自己的 Google 簡報與學習單副本，再依照學生程度、學校類型、可用時間及學科需求進行調整。

課程設計者提供教材模組；現場教師提供對學生的理解與教學專業。

## **七、有效使用 AI 的六字原則**

# **框架**

依據什麼標準思考？

# **流程**

按照什麼步驟執行？

# **脈絡**

需要哪些背景與資料？

不能只告訴 AI「幫我做學習歷程」，而是必須提供明確的任務條件。

| 應用情境     | 可提供的框架或脈絡           |
| -------- | ------------------- |
| 自主學習主題聚焦 | SMART 目標            |
| 資料蒐集與整理  | CODE 知識管理           |
| 學習故事撰寫   | STAR 架構             |
| 困難排除     | GROW 模型、系統性思考、第一性原理 |
| 學習心得與反思  | 認知、情意、技能            |
| 備審資料篩選   | 校系分則、能力特質、學生作品      |
| 成果品質檢核   | 評量規準、檢核表            |

提供越明確的框架、流程與脈絡，AI 就越有機會產出符合需求的結果。

## **八、NotebookLM：建立可對話的知識庫**

NotebookLM 在本課程中的定位，不只是摘要工具，而是教師與學生的個人知識管理系統。

### **知識庫的建立流程**

### **研習中的實際操作示範**

| 應用        | 操作方式                    |
| --------- | ----------------------- |
| 建立學習歷程知識庫 | 匯入官方文件、做伙學資料及教師教材       |
| 學科教學設計    | 詢問如何在國文等學科課程中融入學習歷程     |
| 心智圖生成     | 將回答儲存並轉為來源，再選取相關來源生成心智圖 |
| 教材生成      | 根據篩選過的來源製作簡報與資訊圖表       |
| 技高專題資料庫   | 匯入歷年專題競賽作品，分析主題與製作流程    |
| 校系資料比對    | 匯入學生作品、ColleGo! 及校系審查指引 |
| 研究與自學     | 匯入參考文獻，進行跨文件查詢與分析       |

NotebookLM 的重要價值在於可以限制資料來源、追溯引用依據，降低 AI 產生不可靠資訊的風險，但仍須進行人工查證。

### **資料管理的重要提醒**

原始資料應優先保存在 Google 雲端硬碟等自己能夠管理的位置，再匯入 AI 平臺。

使用任何數位平臺時，都應事先思考：

- 未來是否能夠取回原始資料？
- 帳號停用或離開學校時，資料如何移轉？
- 是否具備備份與版本復原機制？
- 學生作品是否取得適當授權？
- 是否妥善處理個人資料與隱私？

**資料比工具更重要，不應讓個人知識資產被單一平臺綁定。**

## **十、研習中提出的教學現場問題**

| 現場困難           | 可行的調整方向           |
| -------------- | ----------------- |
| 輔導教師入班時間有限     | 將完整課程拆分成獨立模組      |
| 學科教師有教學進度壓力    | 在原有課程中直接融入成果產出    |
| 學生缺乏可整理的素材     | 從高一開始累積，保留課程學習證據  |
| 學生不擅長閱讀長篇資料    | 圖卡、AI 解釋與短篇教材     |
| 學生不知道如何下筆      | 勾選、填空、範例及結構化引導    |
| 不同班型與學生需求差異大   | 依普通班、體育班、實驗班等調整教材 |
| 教師無法即時回應所有問題   | 建立 AI 知識庫與問題解決工具  |
| 校園帳號與設備存在功能限制  | 事前檢查帳號權限、設備及隱私規範  |
| AI 產出可能出現錯字或錯誤 | 教師及學生共同查證與檢核      |

尤其值得重視的是，**學習歷程不能等到課程結束後才要求學生整理，而應在教師設計課程時，就思考學生能夠產生哪些學習成果與證據。**

這涉及教學設計的改變，而不只是資料整理技巧的改善。

## **十一、AI 時代的評量設計**

當學生能夠使用 AI 完成作業時，傳統評量方式也必須跟著調整。

研習最後延伸介紹三個方向：

| 方向                        | 核心精神                          |
| ------------------------- | ----------------------------- |

| AI Assessment Scale（AIAS） | 在課程設計階段明確規範學生可使用 AI 的程度       |
| 專題導向學習 PBL                | 讓學生在真實任務中運用 AI、解決問題及展現能力      |

以醫護專業教育為例，學生即使能夠透過 AI 寫出完整的 CPR 操作說明，也不代表他具備實際執行 CPR 的能力。

因此，評量必須從只看最終答案，轉向關注學生的學習過程、判斷能力、實作表現與問題解決能力。

**AI 應該賦予學生能力（Empower），而不是使學生原有的能力逐漸退化。**

## **十三、整場研習的核心教學觀點**

# **從學習歷程走向終身學習**

讓學生忙於學習，而不是讓老師忙於講述。

讓 AI 協助思考，而不是取代思考。

讓學習歷程成為能力的累積，而不只是升學的文件。

整場研習真正要推動的，是從教師講授、學生被動接收的模式，轉向由教師設計框架、教材提供鷹架、AI 提供即時支持、學生主動操作與反思的學習模式。

教師不需要事事親力親為，但必須掌握學習目標、學習流程與評量方式。學生則必須保有學習的主控權，逐步建立能夠帶離校園的能力。
